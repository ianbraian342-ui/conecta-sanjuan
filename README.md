# 📰 Mi Diario Digital

Un diario digital construido con **HTML, CSS y JavaScript vanilla**, que usa **Supabase** como backend (base de datos y autenticación) y se despliega en **Cloudflare Pages**.

## Descripción

El proyecto consta de dos partes:

- **Portada pública (`index.html`)**: muestra las noticias publicadas en un grid de tarjetas (3 columnas en desktop, 1 en mobile), con imagen, categoría, título, subtítulo, autor y fecha.
- **Panel administrativo (`admin.html`)**: permite registrarse e iniciar sesión como administrador, crear/editar/eliminar noticias y marcarlas como destacadas.

## Requisitos técnicos

- Una cuenta de **Supabase** (gratuita) con un proyecto creado.
- La tabla `noticias` creada en Supabase con las siguientes columnas:
  - `id` (int8, primary key, identity)
  - `titulo` (text, not null)
  - `subtitulo` (text)
  - `contenido` (text)
  - `categoria` (text)
  - `autor` (text)
  - `imagen_url` (text)
  - `destacado` (boolean, default false)
  - `fecha_publicacion` (timestamptz)
- Auth habilitado en Supabase con **Email + Password**.
- Una cuenta de **Cloudflare** para desplegar con Cloudflare Pages.

## Instalación

1. Cloná o descargá este repositorio:

```bash
git clone <URL_DEL_REPOSITORIO>
cd mi-diario
```

2. Abrí la carpeta con tu editor preferido.

3. Probalo localmente con cualquier servidor estático:

```bash
# Opción A: Python
python -m http.server 8080

# Opción B: npx
npx serve .
```

4. Abrí `http://localhost:8080` en el navegador.

> No funciona abriendo `index.html` con doble clic: los archivos JS con `fetch` necesitan servidor HTTP.

## Configuración de Supabase

1. Creá un proyecto en [supabase.com](https://supabase.com).
2. En **SQL Editor**, ejecutá el siguiente script para crear la tabla:

```sql
create table public.noticias (
  id bigint generated by default as identity primary key,
  titulo text not null,
  subtitulo text,
  contenido text,
  categoria text,
  autor text,
  imagen_url text,
  destacado boolean default false,
  fecha_publicacion timestamptz default now()
);
```

3. En **Authentication → Providers**, activá **Email** (y desactivá "Confirm email" si querés registros instantáneos).

4. En **Authentication → URL Configuration**, agregá la URL de tu sitio en *Site URL* y *Redirect URLs*.

5. Copiá la **Project URL** y la **publishable key** desde **Settings → API**.

6. Editá el archivo `js/config.js` con esos valores:

```js
const SUPABASE_URL = 'https://tu-proyecto.supabase.co';
const SUPABASE_ANON_KEY = 'tu_publishable_key';
```

> ⚠️ Nunca uses la `service_role key` en el frontend: expondría el acceso total a tu base de datos.

## Despliegue en Cloudflare Pages

1. Subí el proyecto a un repositorio de GitHub o GitLab.
2. Entrá a [Cloudflare Pages](https://pages.cloudflare.com) → **Create a project**.
3. Conectá tu repositorio.
4. En la configuración del build:
   - **Build command**: dejalo vacío (o `echo "No build required"`)
   - **Build output directory**: `/` (la raíz del proyecto)
5. Hacé clic en **Save and Deploy**.
6. En **Custom domains** podés asociar tu propio dominio.

### Despliegue con Wrangler (CLI)

```bash
# Instalación
npm install -g wrangler

# Login en Cloudflare
wrangler login

# Despliegue
wrangler pages deploy . --project-name=mi-diario
```

## Uso

1. Entrá a `admin.html`.
2. Registrate (o iniciá sesión si ya tenés cuenta).
3. Creá noticias desde el formulario.
4. Marcá alguna como **Destacada** para que aparezca primero en portada.
5. Verificá la portada en `index.html`.
